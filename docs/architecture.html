How GigaWhat works

GigaWhat helps gas and electricity staff find the approved procedure for the job, see the evidence behind it, and get suggested next steps. People make the decisions. It never decides anything safety-critical, and it has no connection to the plant.

Setting
Fictional UK multi-utility, gas and electricity
Users
Field engineers, control room, Authorised Persons, auditors
Data
Public HSE guidance plus fictional procedures and records
Status
Demo shared by link · Phase 1 of 8 built

What it will and won't do

Will

  • Find the approved, current procedure for this asset, site and role
  • Summarise evidence from procedures, incidents, work orders, inspections and alarms, citing every claim
  • Suggest next steps, each tied to a source
  • Send safety-critical work to an Authorised Person for approval

Won't

  • Connect to or operate SCADA, switching or valves
  • Write its own steps for safety-critical work; it quotes the procedure instead
  • Use draft, withdrawn or superseded documents
  • Guess when evidence is thin; it says so and names the document owner

The list of safety-critical topics is a versioned YAML file owned by the safety team, not something buried in a prompt. Changing it is a reviewed change with its own tests.

How retrieval works

Loading documents

  1. Parse with Docling. It keeps headings, numbered steps, tables and WARNING/CAUTION boxes as structure instead of flattening them to text.
  2. Chunk by section. A step is never separated from the warning that goes with it, and every small chunk links to its parent section, so the model sees the whole sequence of steps.
  3. Add a context header. Each chunk carries its breadcrumb and a one-line summary before it is embedded, so a chunk that only says "apply locks" still knows which equipment it is about.
  4. Scan once for injected instructions. Text like "ignore previous instructions" inside a document is flagged when the document is loaded, not on every question.
  5. Version in one transaction. Loading v4 of a procedure marks v3 as superseded at the same moment. v3 stays available for audit questions such as "what did it say on 3 March?"

People and permissions

Visitors pick a persona when they arrive, using Chainlit's chat profiles. No sign-up is needed. A random browser ID keeps each visitor's chats and approvals separate. A persona can't approve its own request, so to see both sides, ask as an engineer and then switch to the Authorised Person.
